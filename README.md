# 🌎 Reconhecimento Local Web

**Reconhecimento Local Web** é uma aplicação web multilíngue desenvolvida para valorizar e dar visibilidade a **negócios, iniciativas, projetos, serviços e ações locais**, conectando sua presença digital a diferentes públicos e mercados.

A aplicação possui suporte a **três idiomas**:

* 🇧🇷 Português
* 🇪🇸 Español
* 🇺🇸 English

O projeto foi desenvolvido com uma arquitetura moderna para aplicações web híbridas, utilizando **Ionic + Angular + TypeScript**, com publicação preparada para **Firebase Hosting**.

> **Seu negócio valorizado em todos os lugares.**

## 💻 Aplicação principal

A aplicação principal está localizada em:

```text
reconhecimento-local-web/
```

Ela foi desenvolvida utilizando **Ionic, Angular e TypeScript**, proporcionando uma base moderna para aplicações web híbridas.

### Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/Reconhecimento-Local-Web.git
```

Acesse a aplicação:

```bash
cd Reconhecimento-Local-Web/reconhecimento-local-web
```

Instale as dependências:

```bash
npm install
```

---

## ▶️ Executar localmente

Para iniciar a aplicação em ambiente local:

```bash
npm start
```

Normalmente, a aplicação estará disponível em:

```text
http://localhost:4200/
```

---

## 📦 Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

O processo de build gera os arquivos necessários para publicação da aplicação.

A configuração atual utiliza a pasta `www` como diretório público para hospedagem.

---

## 🔥 Firebase Hosting

A aplicação possui configuração para publicação utilizando **Firebase Hosting**.

O arquivo de configuração está localizado em:

```text
reconhecimento-local-web/firebase.json
```

### Deploy

Acesse a pasta da aplicação:

```bash
cd reconhecimento-local-web
```

Execute:

```bash
firebase deploy
```

> **Pré-requisito:** é necessário possuir o Firebase CLI instalado e estar autenticado em uma conta do Firebase.

O diretório:


Entre na pasta:

```bash
cd "_archive/site-html-legado"
```

Inicie um servidor HTTP local:

```bash
python -m http.server 8000
```

```text
http://localhost:8000/
```
